# 学习大纲与知识依赖

这是依据已提供材料编排的自学大纲，非学校正式大纲。保留旧稿合理主题顺序，新增三角形与材料界面；07 用于复习，不插断后续主线。

| 学习单元 | 依赖 | 学习目标 |
| --- | --- | --- |
| 01 数学准备 | 微积分、线代 | 模型、离散、求解器和误差来源 |
| 02 一维差分 | 01、Taylor | 守恒到离散，热源与法向符号 |
| 03 二维差分 | 02 | 面系数、五点格式、消元、SPD 条件 |
| 04 杆件弱形式 | 分部积分、平衡 | 降低导数阶，自然边界的来源 |
| 05 一维单元 | 04、插值 | 手算线性/二次元，装配与后处理 |
| 06 二维弱形式 | 04–05、多元积分 | 反应、Robin 项和 Q4 梯度 |
| 08 二维矩阵 | 06 | 域/边载荷、Q9、几何变换和数值积分 |
| 09 三角形 | 行列式、06 | 节点条件、面积坐标、线性场和能量 |
| 10 材料界面 | 06、09 | 分区积分，温度、梯度与通量连续性 |
| 07 复习辅助 | 任意阶段 | 公式查找、自测与后续方向 |

两条主线在 $Ku=F$ 汇合：从点上通量差进入矩阵，或从有限维试探空间进入矩阵。理解这层联系后，换新单元主要是构造新形函数和计算新积分，编号与边界消元原则可以复用。
