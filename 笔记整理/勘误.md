# 本次核查的勘误与来源边界

旧稿保存在项目 `history/notes-before-2026-10-20.zip`。下列修正已进入正文，并非只列在报告中。原始课堂笔记的速记、旧整理稿与当前教材之间需要区分，不能把旧稿错误归给教师。

| 问题 | 当前处理 |
| --- | --- |
| 热源项在正/负对角差分矩阵之间混用 | 统一 $-(kT')'=Q$，用正热源、非零端温验算 |
| $n$ 节点与 $n$ 区间混用 | 统一 $n$ 段、$n+1$ 节点，边界未知量单独计数 |
| 左端热流忽略外法向 | 明确 $n=-1$，区分物理热流与数学通量 |
| 温度曲率“凸、开口向下”说法矛盾 | 正源 $T''<0$，表述为向下凹 |
| 只改已知行仍称保持对称 | 区分单行替换与同时清零行列，保留右端提升项 |
| 罚数法一概称破坏对称 | 对角罚法可对称，但恶化条件数且约束近似 |
| 源项使矩阵严格对角占优 | 源项只改变右端；占优与网格权重、边界有关 |
| 一般 FEM 一定对角占优 | 限定到已证明的差分正权模板，不推广到任意元 |
| 算术平均一概不守恒 | 区分光滑面值插值与界面串联热阻；共享面通量才是守恒关键 |
| 一般条件数写成特征值比 | 一般用奇异值；特征值比限于 SPD |
| $C_0^1$ 仅表示左端为零 | 改用明确的 $V=\{v\in H^1:v|_{\Gamma_D}=0\}$ |
| 变系数 Green 展开漏 $k$ 的导数 | 写作 $\partial_x(k\partial_xu)v+k\partial_xu\partial_xv$ |
| Robin 只改对角 | 写出通常含非对角的边界矩阵 |
| Jacobian 约定不明而混用逆/逆转置 | 固定物理坐标为行的 $J$，梯度用 $J^{-T}$ |
| 三角形必须用参考变换才能积分 | 保留物理坐标解析积分与面积坐标两种方式 |
| 二阶 PDE 必须用二次元 | 弱形式允许线性元；高阶元改善近似能力 |
| 所有二阶元均九节点 | 区分矩形 Q9 与三角形 P2 六节点 |
| 已处理边界就无条件可逆 | 说明正系数、连通分量约束、有效网格和积分的条件 |
| 录音引语、作业、考试结论无法复核 | 从正式要求中移出；页上个人批注不作考试承诺 |
