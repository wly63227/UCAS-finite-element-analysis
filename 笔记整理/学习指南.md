# 学习指南与统一符号

这门课把连续物理场变成有限个未知量的代数问题。贯穿全书的问题是：**如何构造近似，既保留物理规律，又能计算并评估误差？** 有限差分用差商近似导数，有限元先选分片函数，再用积分形式确定系数。两条路线在热传导与弹性杆上可以互相校验。

## 学习路线

第一次按 01、02、03、04、05、06、08、09、10 阅读，最后用 07 自测。已有差分基础者可从 04 开始，但应先掌握[边界符号](./02-一维稳态热传导的有限差分法.md#kp-boundary-flux)。

| 阶段 | 学会的动作 | 前置工具 |
| --- | --- | --- |
| 01–03 连续模型与差分 | 守恒建模、三对角/五点格式、消元 | 微积分、Taylor、线性方程组 |
| 04–05 一维有限元 | 弱形式、形函数、单元矩阵与装配 | 分部积分、矩阵乘法、杆件平衡 |
| 06、08 二维标量问题 | Green 公式、Q4/Q9、域与边界积分 | 多元微积分、法向、二重积分 |
| 09–10 三角形与界面 | 面积坐标、线性场恢复与通量平衡 | 行列式、仿射函数、分区积分 |

不必先掌握全部泛函分析。$H^1$ 允许连续分片函数具有平方可积的一阶弱导数；本书不是存在唯一性理论的完整证明教材。

## 怎样读正文与例题

章首说明实际来源。“补充”推导、反例和实验由编写者添加。01、04–06 保留规范化课堂提纲并补写解释，不是逐字转录。标为待核的参考书章节号只是旧稿查找线索。公式应先看问题，再检查量和条件，最后亲自推导一次。例题先手算，再运行[实验](./练习与实验.md)。当前没有独立可核实的教师作业原题，练习均明确为自拟。

## 统一符号

| 符号 | 对象与角色 | 约定/单位 |
| --- | --- | --- |
| $\Omega,\partial\Omega,\Gamma_I$ | 区域、外边界、材料界面 | 二维时面积/曲线 |
| $n,\partial_n$ | 外单位法向、法向导数 | 界面两侧法向相反 |
| $T,u,u_h$ | 温度、一般场或杆位移、近似函数 | 温度 K，位移 m，依模型说明 |
| $v,\bar u$ | 检验函数 | 在 Dirichlet 部分取零 |
| $u_i,u_e$ | 节点值、单元节点列向量 | 与连续函数区分 |
| $k,p$ | 已知扩散或一维主系数 | 热学 $k$ 为 W/(m·K) |
| $Q,f$ | 体热源、一般右端/线载荷 | 依模型为 W/m³、N/m 等 |
| $q_n,g$ | 物理外向热流、数学外向通量 | 热学 $g=-q_n$ |
| $q(x)$ | ODE 反应系数 | 不同于热流 $q_n$ |
| $\alpha,T_\infty$ | Robin 系数、环境温度 | 热学 $g=\alpha T_\infty$ |
| $E,S,\rho gS,P$ | 弹性模量、截面积、自重线载荷、端力 | Pa、m²、N/m、N |
| $h,\ell_e,n$ | 网格尺度、单元长度、单元数 | $n$ 段有 $n+1$ 个线性节点 |
| $N,B,K^e,K,F$ | 形函数、梯度、单元/总矩阵、载荷 | 标量 $m$ 节点元 $B$ 为 $d\times m$ |
| $J$ | 几何映射 Jacobian | 行为物理坐标，列为参考坐标；梯度用 $J^{-T}$ |
| $A,L_i$ | 三角形面积、面积坐标 | $\sum L_i=1$ |
| $F,D$（下标） | 自由/已知自由度集合 | 不同于载荷向量 $F$ |

旧提纲有时将 $u_h$ 简写为 $u$，指有限维空间内的近似，注意上下文。$\Gamma_D,\Gamma_N,\Gamma_R$ 分别对应旧稿的 $\partial\Omega_1,\partial\Omega_2,\partial\Omega_3$；后者也指边界部分，不是求解区域自身。
