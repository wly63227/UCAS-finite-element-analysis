一、课堂内容规范化整理（非逐字）#

数学分析 → 函数、代数、数值分析、有限元 数值解法 → 差分（离散点） 有限元法 / 边界元法 / 有限体积法 / 谱方法 传热学 → 差分法

静止介质中的热传导方程（能量守恒结合傅里叶定律）：

ρc ∂T∂t=∇⋅k∇T+Q\rho c\,\frac{\partial T}{\partial t}=\nabla\cdot k\nabla T+Qρc∂t∂T​=∇⋅k∇T+Q

短短几行其实交代了整门课的三件事：问题的来源（数学分析 → 微分方程）、 求解的路线（离散 → 代数方程组）、方法的家族（差分、有限元、边界元、有限体积、谱方法）。

二、逐条解释与补充#

2.1 为什么"数学分析 → 数值分析 → 有限元"是一条链#

数学分析研究极限、连续、微分、积分及其理论，并不以解能写成解析表达式为前提；一旦区域形状不规则、系数可变、边界条件复杂， 解析解基本写不出来，只能求近似解。近似解有两种典型来源：

  • 把连续的自变量离散成有限个点（差分法）：导数用差商代替，一阶导数的三种差分见 02-一维稳态热传导的有限差分法。
  • 把解限制在有限维函数空间里（有限元、谱方法）：设定 u(x)≈∑Ni(x)uiu(x)\approx\sum N_i(x)u_iu(x)≈∑Ni​(x)ui​， 要求某个积分意义下的误差为零。这就是有限元的起点。

在本书的线性稳态模型中，两条路最后都归结为线性代数方程组 [A]{u}={f}[A]\{u\}=\{f\}[A]{u}={f}，所以《数值分析》里的 直接法（追赶法、LU）、迭代法（Jacobi、SOR、共轭梯度）是这门课的工具箱。

2.2 五种方法的定位#

方法 离散对象 优点 缺点 本课程位置
有限差分 区域上的网格节点 构造简单、格式直观 不规则区域难处理、边界精度低 P1–P3 重点
有限元 区域的单元划分 + 基函数 几何适应性强、边界条件自然处理、理论完备 需要网格与插值、装配过程繁琐 P4–P12 重点
边界元 只离散边界 降一维、适合无限域 需要基本解、系数矩阵满阵 未展开
有限体积 控制体（守恒通量） 严格守恒、适合流体 高阶精度难达到 未展开
谱方法 全局光滑基函数 光滑解精度极高 复杂几何与间断解适应性差 未展开

老师笔记里"传热学 → 差分法"的意思是：这一节的物理背景取自传热学（稳态/瞬态导热）， 处理手段暂时用差分法；到了有限元部分，物理背景会换成材料力学/弹性力学。

2.3 热对流扩散方程逐项解释#

项 名称 物理含义
ρc ∂T/∂t\rho c\,\partial T/\partial tρc∂T/∂t 时间项（非定常项） 单位体积内能随时间的变化率
ρc V⋅∇T\rho c\,\boldsymbol{V}\cdot\nabla TρcV⋅∇T 对流项 流体带着热量迁移（V\boldsymbol VV 为流体速度）
∇⋅(k∇T)\nabla\cdot(k\nabla T)∇⋅(k∇T) 扩散项 傅里叶定律 + 能量守恒得到的净导热
QQQ 源项 单位体积、单位时间的内部产热（如核衰变、电阻发热）

笔记 P3 顶部把右端注释为**"单位体积内平均产/燃率"**，即 QQQ 是体热源密度。

傅里叶定律（本构关系，不是守恒律）：

q=−k∇T\boldsymbol{q}=-k\nabla Tq=−k∇T

即热流密度与温度梯度成正比、方向相反。把它代入能量守恒 ρc ∂T/∂t=−∇⋅q+Q\rho c\,\partial T/\partial t=-\nabla\cdot\boldsymbol{q}+Qρc∂T/∂t=−∇⋅q+Q 就得到上面那个方程。这个"守恒律 + 本构关系 → 控制方程"的推导思路后面还会用两次 （力学里换成"平衡 + 胡克定律"，见 P4）。

若 V=0\boldsymbol V=\boldsymbol 0V=0（固体，无流动），对流项消失，退化为热传导方程：

ρc ∂T∂t=∇⋅(k∇T)+Q\rho c\,\frac{\partial T}{\partial t}=\nabla\cdot(k\nabla T)+Qρc∂t∂T​=∇⋅(k∇T)+Q

若再令 ∂T/∂t=0\partial T/\partial t=0∂T/∂t=0（或 ρc ∂T/∂t=0\rho c\,\partial T/\partial t=0ρc∂T/∂t=0，笔记 P2 写的就是这一步）， 得到本课程实际要解的第 1 个模型问题：

2.4 物质导数（笔记 P2 上半页会用到）#

笔记 P2 出现 dTdt=∂T∂t+V⋅∇T\frac{\mathrm dT}{\mathrm dt}=\frac{\partial T}{\partial t}+\boldsymbol V\cdot\nabla TdtdT​=∂t∂T​+V⋅∇T， 这是物质导数/全导数：跟随流体质点观察温度变化，由"局部变化 + 迁移变化"两部分组成。 对应两种参考立场：

  • Euler 表述：固定空间点看物理量随时间的变化 → 出现 ∂T/∂t\partial T/\partial t∂T/∂t。
  • Lagrange 表述：跟随质点看物理量的变化 → 出现 DT/Dt\mathrm DT/\mathrm DtDT/Dt。

两种描述跟踪对象不同。Euler/Lagrange 与守恒/非守恒是两组不同分类，不能一一对应；这里的物质导数由链式法则得到。

四、适定性与误差来源（理解"为什么强调收敛性"）#

  • 适定性：解存在、唯一、且连续依赖数据。Hadamard 意义下，椭圆型边值问题在合理条件下是适定的； 反问题（如由地面运动反演震源）往往不适定，需要正则化。
  • 三类误差：
    1. 模型误差（方程本身是近似，如忽略温度对 kkk 的影响）；
    2. 离散误差（用差分/插值代替连续算子，O(h2)O(h^2)O(h2) 之类，这门课的理论主线）；
    3. 舍入误差（浮点运算，见 P7：一般 κ2(A)=σmax⁡/σmin⁡\kappa_2(A)=\sigma_{\max}/\sigma_{\min}κ2​(A)=σmax​/σmin​，仅对称正定阵可写成特征值最大最小之比）。

记忆点：离散误差靠加密网格/提高阶数减小；常见未预处理的刚度矩阵条件数随网格加密增大，舍入与数据误差的放大上界可能增大；实际误差并非每次必增。 这两者的矛盾是数值方法里永恒的张力，笔记 P7 专门写了这一点。

五、复习要点（P1 层面）#

  1. 能默写热对流扩散方程并逐项说出物理含义。
  2. 能说清"守恒律 + 傅里叶定律 → 控制方程"的推导顺序。
  3. 能对比五种数值方法的适用场合（至少说出有限元相对差分法的两个优势）。
  4. 能按判别式给 PDE 分类，并说出各自的定解条件格式。
